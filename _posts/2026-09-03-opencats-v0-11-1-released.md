## OpenCATS v0.11.1 is available

OpenCATS v0.11.1 is now available from the [OpenCATS GitHub releases page](https://github.com/opencats/OpenCATS/releases/tag/v0.11.1).

This is primarily a security and maintenance release. It includes additional hardening in import handling, candidate merge processing, installer validation, advanced search output escaping, and extra-field validation.

The release also includes Career Portal fixes, improved installer and legacy database upgrade coverage, restored full release packages containing production dependencies, and expanded contributor documentation.

OpenCATS v0.11.1 is tested against PHP 8.4.1 and PHP 8.5. The release pipeline runs PHPUnit unit and integration tests together with the default and security Behat suites.

Users running older OpenCATS releases are encouraged to upgrade. As always, take a complete backup of the OpenCATS database and attachments before upgrading.

* [Download OpenCATS v0.11.1](https://github.com/opencats/OpenCATS/releases/tag/v0.11.1)
* [Read the installation documentation](https://documentation.opencats.org)
* [Review published security advisories](https://github.com/opencats/OpenCATS/security/advisories)
* [Join GitHub Discussions](https://github.com/opencats/OpenCATS/discussions)

If you encounter an issue with the release, please report it in the [OpenCATS GitHub issue tracker](https://github.com/opencats/OpenCATS/issues).
